# TCM Clinic Manager

Clinic management app (patients, visits, appointments, herb inventory, receipts).

## Install (Windows)
1. Download `TCM-Clinic-Manager-Setup.zip`.
2. Right-click > Extract All.
3. Double-click `Install.bat` (if Windows warns, click More info > Run anyway).
4. Open the "TCM Clinic Manager" icon on the Desktop.

All data stays on your own computer. Back up regularly from Settings & Backup.

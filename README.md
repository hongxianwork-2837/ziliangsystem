# TCM Clinic Manager 中医诊所管理系统

Patients, TCM visit records, appointments, herb inventory and receipts. 病人资料、中医就诊记录、预约、药材库存和收据。

## Install (Windows) 安装
1. Download `TCM-Clinic-Manager-Setup.zip` 下载压缩包
2. Right-click > Extract All 右键 > 全部提取
3. Double-click `Install.bat` 双击 Install.bat（Windows 若提示保护电脑：更多信息 > 仍要运行）
4. Open the "TCM Clinic Manager" icon on the Desktop 打开桌面图标

Chinese by default; click "English" (bottom left) to switch. 默认中文，左下角可切换英文。
All data stays on your own computer. Back up regularly. 资料只保存在本机，请定期备份。
